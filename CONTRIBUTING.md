# Contributing

Directbox Series welcomes corrections, citations, independent research notes, and narrowly scoped experimental prototypes.

## Before contributing
1. Read the roadmap and architecture proposal.
2. Open an issue stating the hypothesis, public sources, and proposed test.
3. Keep demonstrations self-authored or otherwise properly licensed.
4. Document the environment, commands, expected output, actual output, and limitations.

## Evidence labels
- **Proposal:** idea or planned architecture.
- **Research:** a source-backed analysis.
- **Prototype:** runnable code with reproducible observations.
- **Verified:** result independently reproduced with documented setup.

Do not describe a proposal as a verified implementation.

## Boundaries
Do not upload console keys, firmware, proprietary SDK components, leaked game binaries or assets, or instructions aimed at bypassing access controls. This repository is not affiliated with Microsoft, Rockstar Games, or Take-Two Interactive.

## Style
Concise technical writing, precise terminology, reproducibility over speculation. English is preferred for public-facing documentation.
